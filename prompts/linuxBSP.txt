以下是一份針對具備基於 Linux BSP 開發 IoT 產品經驗的工作技能描述，適合用於招聘相關專業人才：

---

## **職位名稱**
嵌入式 Linux BSP 產品開發經理（IoT 專案）

## **工作職責**
- 負責嵌入式 Linux BSP 的設計、開發與維護，支持 IoT 設備的硬體平台。
- 執行硬體平台的初始啟動（Board Bring-up）及相關調試工作。
- 開發和優化 Linux 核心模組及設備驅動程式，確保與硬體的高效互操作性。
- 配置和定制 Yocto、Buildroot 或其他嵌入式 Linux 构建系統，用於生成 BSP 和完整軟件映像。
- 集成和實現 IoT 協議（如 MQTT、LoRa、BLE 等）及相關網絡功能。
- 協助硬體團隊進行電路板設計審核，並提供低層軟件支持。
- 實施安全機制（如安全啟動、加密/解密），以保護 IoT 設備的數據與通信安全。
- 執行軟件測試和調試，並撰寫高質量的技術文檔。

## **技能要求**
### **必備技能**
1. **嵌入式開發經驗**：
   - 至少 3 年以上嵌入式 Linux BSP 開發經驗，熟悉 ARM 或 MIPS 架構。
   - 熟悉 Linux 核心內部結構及設備驅動開發。

2. **技術專長**：
   - 精通 C/C++ 編程語言，具備 Shell 或 Python 腳本編寫能力。
   - 熟悉設備樹（Device Tree）配置與調試。
   - 熟悉 U-Boot 或其他 Bootloader 的定制與開發。
   - 熟悉交叉編譯工具鏈及構建系統（如 Yocto、Buildroot）。

3. **硬體相關經驗**：
   - 熟悉常見硬體介面（如 SPI、I2C、UART、GPIO）。
   - 具備新硬體平台的啟動和調試能力。

4. **IoT 領域知識**：
   - 熟悉 IoT 通信協議（如 MQTT、CoAP）及網絡技術（如 WiFi、藍牙）。
   - 瞭解 IoT 設備的遠程更新（FUOTA）及設備管理。

5. **問題解決能力**：
   - 能夠快速定位並解決 BSP 層面或驅動層面的錯誤。

### **加分項**
- 熟悉多媒體處理（如 GStreamer）或圖形系統（如 Wayland/Weston）。
- 具備容器技術經驗（如 Docker 或 Kubernetes）。
- 參與過 Yocto 項目或其他開源社區貢獻經驗尤佳。
- 瞭解安全啟動機制及數據保護技術。

## **軟性技能**
- 優秀的團隊合作與溝通能力，能與跨部門團隊協作完成項目交付。
- 主動學習新技術，適應快速變化的技術環境。

## **教育背景**
- 電子工程、計算機科學或相關領域本科以上學歷。

## **工作地點**
台北
